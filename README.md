# Robot Game

A 3D open-world mech combat game that runs in the browser. Pilot a light, medium or heavy suit
across an 8 km world of four biomes where four factions are at war, salvage parts from what you
destroy, and choose a side, or none.

Built with [Babylon.js](https://www.babylonjs.com/) and TypeScript. All content is original.

## Playing

Open the game's link in a recent desktop browser (Chrome, Edge, Firefox or Safari) and click
**Deploy**. The first mission teaches the controls; every key can be changed from the pause menu
(Esc), which also has the accessibility options. A standard gamepad works too. Progress saves
by itself, in three slots, in the browser.

## Developing

```sh
npm install
npm run dev        # http://localhost:5173
npm run check      # typecheck, unit tests and browser tests
npm run e2e:prod   # the browser tests against the production build
npm run build      # production build in dist/
```

`CLAUDE.md` describes the architecture and the things that are easy to get wrong; the roadmap
is in `docs/roadmap.md`. Hosting and sharing the build: `docs/hosting.md`.
